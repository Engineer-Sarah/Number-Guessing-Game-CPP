# 🎯 Number Guessing Game — C++

A console-based Number Guessing Game developed in C++ as a practical programming project.

The player chooses a difficulty level and tries to guess a randomly generated number using hints and a limited number of attempts.

## ✨ Features

- 🎮 Easy, Medium, and Hard difficulty levels
- 🔢 Random number generation from 1–100
- 💡 "Too High / Too Low" hints
- 🎯 Limited attempts
- 🔁 Replay option
- 💻 Console-based interface

## 🛠️ Technologies

- C++
- Microsoft Visual Studio

## 🧠 Concepts Practiced

- Variables and data types
- Conditional statements
- Loops
- Functions
- Random number generation
- User input/output
- Basic game logic

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Engineer-Sarah/Number-Guessing-Game-CPP.git
cd Number-Guessing-Game-CPP
```

2. Open the project/source file in Microsoft Visual Studio.
3. Build and run the program.
4. Follow the instructions shown in the console.
